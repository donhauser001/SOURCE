## Phase 1: 基础设施

### P1-1: 数据库模型定义
**角色**：开发  
**预估**：4h  
**产出**：`prisma/schema.prisma` 更新

**任务内容**：
1. 新增枚举类型：
   - `ContentType`: WORK, TUTORIAL, ARTICLE
   - `ContentStatus`: DRAFT, PENDING, PUBLISHED, REJECTED, ARCHIVED
   - `FeaturedLevel`: NONE, EDITOR_PICK, HOMEPAGE
   - `ReviewAction`: APPROVE, REJECT, REQUEST_CHANGE, SET_FEATURED, UNSET_FEATURED, ARCHIVE, RESTORE

2. 新增数据模型：
   - `Content` - 统一内容表
   - `ContentCategory` - 多级分类表
   - `ContentColor` - 内容-颜色关联表
   - `ContentReview` - 审核记录表

3. 更新现有模型：
   - `User` 添加 `contents` 和 `contentReviews` 关联
   - `Color` 添加 `contentColors` 关联
   - `ColorBook` 添加 `contents` 关联

**验收标准**：
- [ ] `prisma validate` 通过
- [ ] 所有索引正确定义
- [ ] 关联关系正确设置

   - 支持 tags 筛选

**验收标准**：

4. `submit` - 提交审核（需登录，仅作者，仅草稿）
5. `myContents` - 我的内容列表（需登录）

**验收标准**：

4. `archive` - 归档（需 OPERATOR/ADMIN）
5. `restore` - 恢复归档（需 ADMIN）
