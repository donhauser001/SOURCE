# SOURCE 版本计划表

> 版本号规则：`主版本.次版本.修订号`  
> - 主版本：重大架构变更或里程碑  
> - 次版本：功能模块完成  
> - 修订号：Bug 修复、小优化  

---

## 核心认知

```
SOURCE 不是一个商城
SOURCE 也不是一个插件
SOURCE 是一个"标准系统"，其它都是围绕它旋转的接口层

AI 是放大器，不是基础设施
CLI 是系统接口，不是玩具
Analyze 只吃事实，不吃想象
```
