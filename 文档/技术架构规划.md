# SOURCE 官网技术架构规划

> 版本：V1.0  
> 更新日期：2026-01-07  
> 核心原则：AI 是系统的一等操作主体，任何功能必须同时满足人可操作、AI 可操作、可脚本化。

---

## 一、项目定位

SOURCE 官网是"实体印刷色彩实操体系"的信息门户，承载以下核心职能：

| 职能 | 说明 |
|------|------|
| 色彩身份证 | 每个 Color ID 的专属页面，包含真源数据、材质表现、油墨配方 |
| 生产指导书 | 印厂机长可直接依据页面信息调墨生产 |
| 电商入口 | 打样包销售、权限验证码发放 |
| 插件数据源 | 为 Adobe 插件提供色彩数据 API |

## 二、技术栈选型

### 2.1 核心框架

| 技术 | 版本 | 选型理由 |
|------|------|---------|
| Next.js | 15.x (App Router) | SSG/SSR 混合渲染，色彩身份证页面需要 SEO；API Routes 可作为 AI 操作入口 |
| TypeScript | 5.x | 类型安全，AI 可解析接口契约，减少歧义 |
| React | 19.x | Next.js 默认，生态成熟 |

### 2.2 UI 层

| 技术 | 选型理由 |
|------|---------|
| shadcn/ui | **强制约束**，项目唯一 UI 组件库 |
| Tailwind CSS | shadcn/ui 依赖，原子化样式 |
| Lucide Icons | **强制约束**，禁止 Emoji，统一使用 Lucide 图标 |

### 2.3 数据层

| 技术 | 选型理由 |
|------|---------|
| PostgreSQL | 结构化色彩数据（Lab 值、配方比例）；支持 JSONB 存储灵活属性；支持数组类型存储多纸张数据 |
| Prisma | 类型安全 ORM，schema 即文档，AI 可直接理解数据模型 |
| tRPC | 端到端类型安全 API；AI 可通过类型化接口操作，无需猜测参数 |

### 2.4 状态与流程

| 技术 | 选型理由 |
|------|---------|
| XState v5 | **流程 = 状态机**，订单流程、权限验证等用状态机建模，禁止页面驱动流程 |
| Zustand | 轻量客户端状态管理，store 结构清晰，AI 可读 |

### 2.5 认证与支付

| 技术 | 选型理由 |
|------|---------|
| NextAuth.js (Auth.js) | 开源、可自托管、支持多 Provider（邮箱、微信、GitHub） |
| Stripe | 国际支付，打样包电商需要 |
| 微信支付 / 支付宝 | 国内支付覆盖 |

### 2.6 基础设施

| 技术 | 选型理由 |
|------|------|
| Vercel / Docker 自托管 | Vercel 适合快速迭代；自托管保留数据主权 |
| Cloudflare R2 / 阿里 OSS | 高清扫描图、纸张纹理图存储，需 CDN 加速 |
| Meilisearch | 色号搜索、配方搜索，轻量易部署，支持中文分词 |

### 3.2 核心原则

| 原则 | 说明 |
|------|------|
| **UI 无独占能力** | 任何 UI 能做的事，AI 必须能通过同一 API 完成 |
| **流程 = 状态机** | 订单、支付、权限验证等流程用 XState 建模，禁止页面驱动 |
| **真源数据不可变** | Color ID 的 Lab 真源值一旦录入，不可修改，只可废弃并新建 |
| **开放差异** | 同一 Color ID 在不同纸张上的表现数据独立存储，不做"平均"或"修正" |

## 四、数据模型设计

### 4.1 核心实体

```prisma
// 色彩身份证
model Color {
  id            String   @id @default(cuid())
  colorId       String   @unique  // 固定编号，如 "CN-Song-04"
  name          String            // 文化名称，如 "烟雨青"
  
  // 真源数据 (The True Source)
  labL          Float             // L* 值
  labA          Float             // a* 值
  labB          Float             // b* 值
  measuredAt    DateTime          // 测量时间
  measuredBy    String            // 测量设备型号
  
  // 油墨配方
  inkRecipe     Json              // { "冲淡剂": 70, "射光蓝": 20, "荧光红": 10 }
  deltaETolerance Float @default(2.0)  // 生产容差 ΔE
  
  // 关联
  paperProfiles PaperProfile[]    // 各纸张表现数据
  proofingPacks ProofingPack[]    // 打样包 SKU
  
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
}

// 纸张表现数据
model PaperProfile {
  id            String   @id @default(cuid())
  colorId       String
  color         Color    @relation(fields: [colorId], references: [id])
  
  paperType     PaperType         // 纸张类型枚举
  
  // 该纸张上的实测 Lab
  labL          Float
  labA          Float
  labB          Float
  
  // 材质特性
  glossiness    Float             // 光泽度 0-100
  inkAbsorption Float             // 吸墨率 0-100
  gamutCoverage Float             // 色域覆盖率 0-100
  
  // 高清扫描图 URL
  scanImageUrl  String
  
  // 推荐等级
  recommendation Recommendation   // BEST / GOOD / CAUTION / AVOID
  cautionNote   String?           // 风险说明
  
  createdAt     DateTime @default(now())
}

enum PaperType {
  PREMIUM_MATTE      // 高阶映画
  UNCOATED           // 纯质纸
  COATED             // 铜版纸
  OFFSET             // 双胶纸
  LIGHTWEIGHT        // 轻型纸
}

enum Recommendation {
  BEST      // 最佳拍档
  GOOD      // 表现良好
  CAUTION   // 需注意
  AVOID     // 建议慎用
}

// 打样包 SKU
model ProofingPack {
  id            String   @id @default(cuid())
  colorId       String
  color         Color    @relation(fields: [colorId], references: [id])
  
  paperType     PaperType         // 一纸一包
  price         Int               // 价格（分）
  stock         Int               // 库存
  
  createdAt     DateTime @default(now())
}
```

### 4.2 状态机定义（订单流程示例）

```typescript
// 订单状态机 (XState v5)
import { setup } from 'xstate';

export const orderMachine = setup({
  types: {
    context: {} as {

  initial: 'draft',
  states: {
    draft: {
      on: { SUBMIT: 'pending_payment' },

      },
    },
    paid: {
      on: {
        SHIP: 'shipped',
        CANCEL: 'refunding',
      },
    },
    shipped: {
      on: { DELIVER: 'completed' },
    },
    completed: { type: 'final' },
    cancelled: { type: 'final' },
    refunding: {
      on: { /* 退款流程 */ },
    },
  },
});
```

## 六、开发规范

### 6.1 AI 可操作性检查清单

每个功能上线前，必须通过以下检查：

- [ ] 该功能是否有对应的 tRPC procedure？
- [ ] AI 是否能通过 API 完成该操作，无需 UI？
- [ ] 流程是否用状态机建模，而非页面跳转？
- [ ] 错误信息是否结构化（code + message），而非仅 UI 提示？

### 6.2 禁止事项

| 禁止 | 正确做法 |
|------|---------|
| Emoji | 使用 Lucide Icons |
| 自定义 UI 组件库 | 使用 shadcn/ui |
| 页面驱动流程 | 状态机驱动 |
| 核心逻辑写在前端事件中 | 逻辑下沉到 server/services |
| 假进度条、假思考动画 | 真实状态反馈 |

### 6.3 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 文档文件 | 中文命名 | `技术架构规划.md` |
| 代码文件 | kebab-case | `color-service.ts` |
| 组件 | PascalCase | `ColorCard.tsx` |
| tRPC procedure | camelCase | `color.getById` |
| 数据库表 | PascalCase (Prisma) | `Color`, `PaperProfile` |

## 七、AI-ready 架构预留（CLI-first 路线）

> 核心策略：**不做提示词工程，不暴露一堆 API，给 AI 最小可调用工具。**  
> 把 AI 当成"操作员"而非"聪明聊天者"——只能执行白名单 CLI 命令，每次调用都留下审计日志。

### 7.1 CLI-first 路线定位


### 7.2 最小架构组件

#### 组件 A：SOURCE CLI（AI 唯一入口）

```bash
# CLI 名称：source
# 负责把复杂业务动作收敛成少数命令
# AI 只看到命令与 JSON 输出，内部实现对 AI 透明

source <command> [options] --json
```

**设计原则**：
- 命令面向**任务**，不面向数据表
- 输入只允许 JSON 或明确 flags
- 输出永远 JSON
- 错误永远结构化
- 每条输出带 citations

#### 组件 B：执行沙箱

AI 运行在受控环境里：

| 限制项 | 说明 |
|--------|------|
| 命令白名单 | 只能运行 `source` 命令 |
| 网络隔离 | 不能任意联网（或仅允许访问自有域名） |
| 文件系统 | 权限隔离，最好只读 + 单独工作目录 |

#### 组件 C：CLI 级权限模型（不靠提示词）

```bash
# 通过环境变量或 flag 控制权限
export SOURCE_API_KEY="sk_..."
export SOURCE_PROFILE="ai-readonly"

# 或
source color get --id CN-Song-04 --role ai-readonly --scope read:color,read:paper --json
```

| 权限级别 | 说明 |
|---------|------|
| `ai-readonly` | AI 专用，只读，永久禁止写真源数据 |
| `plugin-paid` | 插件付费用户，可读配方/扫描图 |
| `admin` | 管理员，可写入 |

**铁律**：所有写操作默认禁用，或要求人工确认 token。

#### 组件 D：审计日志（必须）

每次 CLI 调用记录：

```typescript
interface AuditLog {
  timestamp: string;        // 调用时间
  caller: string;           // 调用者（ApiKey ID / User ID）
  command: string;          // 命令名
  args: Record<string, unknown>;  // 参数摘要（脱敏）
  result: 'success' | 'error';
  errorCode?: string;
  duration: number;         // 执行耗时(ms)
  citations: string[];      // 引用对象（ColorID、BatchID 等）
}
```

### 7.4 I/O 规则（替代提示词工程的"硬规则"）

| 规则 | 说明 |
|------|------|
| 输入格式 | 只允许 JSON 或明确 flags，禁止自由文本 |
| 输出格式 | 永远 JSON，包含 `ok` 字段 |
| 错误格式 | `{ ok: false, code, message, details }` |
| 引用必带 | 每条输出必须带 `citations` 数组 |
| 无数据处理 | 返回 `no_record` 时，AI 必须说"暂无验证记录" |
| 成本输出 | 只能输出"区间 + 假设"，禁止确定报价 |

### 7.6 风险规避策略

| 风险 | 规避措施 |
|------|---------|
| **命令越来越多，失控** | 把命令当"产品接口"，新增命令需满足：覆盖明确用户任务、可审计、有权限边界、有稳定 schema |
| **AI 仍然可能"编答案"** | 规定：回答必须包含 citations[]；CLI 返回 no_record 时必须说"暂无验证记录"；成本只能输出"区间+假设" |
| **写操作安全** | AI 账号永久只读；即使未来允许写，`--dry-run` 默认开启，需人类签发一次性确认 token |

## 八、工程色彩分析系统（SourcePack）

> 核心策略：**上传工程 → 结构化解析 → 可审计推荐**，而不是"上传文件 → AI 猜"。

### 9.2 SourcePack 数据格式（`.sourcepack.json`）

```typescript
// packages/api-types/src/sourcepack.ts

/**
 * SourcePack 工程色彩包格式
 * 版本：1.0
 */
export interface SourcePack {
  /** 格式版本 */
  version: '1.0';
  
  /** 导出时间 */
  exportedAt: string;
  
  /** 工程文档信息 */
  doc: DocInfo;
  
  /** 印刷意图 */
  printIntent: PrintIntent;
  
  /** 颜色清单 */
  colors: ColorUsage[];
  
  /** 约束条件 */
  constraints: Constraints;
  
  /** 附件（可选，用于人工复核） */
  attachments?: Attachment[];
}

/** 文档信息 */
interface DocInfo {
  /** 软件名称 */
  app: 'photoshop' | 'illustrator' | 'indesign';
  /** 软件版本 */
  appVersion: string;
  /** 色彩模式 */
  colorMode: 'CMYK' | 'RGB' | 'LAB';
  /** 文档尺寸 (mm) */
  size: { width: number; height: number };
  /** 页数（ID 适用） */
  pages?: number;
}

/** 印刷意图 */
interface PrintIntent {
  /** 用途 */
  useCase: 'book_cover' | 'book_text' | 'packaging' | 'poster' | 'brochure' | 'other';
  /** 印量（可选） */
  quantity?: number;
  /** 地区（影响成本/纸源） */
  region?: string;
  /** 工艺偏好 */
  finishing?: Array<'lamination_matte' | 'lamination_gloss' | 'hot_stamping' | 'embossing' | 'uv_coating'>;
  /** 纸张候选（用户预选） */
  paperCandidates?: PaperType[];
}

/** 颜色使用情况 */
interface ColorUsage {
  /** SOURCE Color ID（优先） */
  colorId?: string;
  
  /** 回退值（若无匹配 Color ID） */
  fallback?: {
    lab?: { L: number; a: number; b: number };
    rgb?: { r: number; g: number; b: number };
    cmyk?: { c: number; m: number; y: number; k: number };
  };
  
  /** 使用情况 */
  usage: {
    /** 面积占比 (0-1) */
    areaRatio: number;
    /** 是否有大色块 */
    largeSolidBlocks: boolean;
    /** 是否有渐变 */
    gradients: boolean;
    /** 是否与黑叠印 */
    overprintWithBlack: boolean;
    /** 是否用于文字 */
    usedInText: boolean;
  };
}

/** 约束条件 */
interface Constraints {
  /** 预算敏感度 */
  budgetSensitivity: 'low' | 'medium' | 'high';
  /** 纸张偏好（文字描述） */
  paperPreferences?: string;
  /** 必须避免的纸张 */
  avoidPapers?: PaperType[];
}

/** 附件 */
interface Attachment {
  /** 类型 */
  type: 'preview' | 'reference';
  /** 文件名 */
  filename: string;
  /** Base64 数据（可选，建议外链） */
  data?: string;
  /** 外链 URL */
  url?: string;
}

type PaperType = 'PREMIUM_MATTE' | 'UNCOATED' | 'COATED' | 'OFFSET' | 'LIGHTWEIGHT';
```

```typescript
  /** 严重程度 */
  severity: 'low' | 'medium' | 'high';
  /** 描述 */
  description: string;
  /** 涉及颜色 */
  affectedColors: string[];
  /** 建议 */
  suggestion: string;
}

/** 纸张推荐 */
interface PaperRecommendation {

  /** 纸张类型 */

  /** 综合评分 (0-100) */

  /** 引用类型 */

  id: string;
```

```typescript
// apps/web/src/server/services/recommendation-engine.ts

export async function generateRecommendations(
  sourcepack: SourcePack,
  ctx: Context
): Promise<AnalysisReport> {
  
  // 1. 解析颜色，映射到 SOURCE Color ID
  const colorAnalysis = await analyzeColors(sourcepack.colors);
  
  // 2. 识别风险点
  const risks = identifyRisks(sourcepack, colorAnalysis);
  
  // 3. 获取所有候选纸张的 PaperProfile
  const paperProfiles = await getPaperProfiles(colorAnalysis.verifiedColorIds);
  
  // 4. 对每种纸张计算综合评分
  const scores = PAPER_TYPES.map(paperType => ({
    paperType,
    score: calculateScore(paperType, {
      colorAnalysis,
      risks,
      paperProfiles,
      printIntent: sourcepack.printIntent,
      constraints: sourcepack.constraints,
    }),
  }));
  
  // 5. 排序，取 Top 3 推荐 + 避坑列表
  const sorted = scores.sort((a, b) => b.score - a.score);
  const recommendations = sorted.slice(0, 3).map((s, i) => ({
    rank: i + 1,
    paperType: s.paperType,
    score: s.score,
    pros: generatePros(s),
    cons: generateCons(s),
    evidence: gatherEvidence(s),
  }));
  
  const avoidList = sorted
    .filter(s => s.score < AVOID_THRESHOLD)
    .map(s => ({
      paperType: s.paperType,
      reason: generateAvoidReason(s),
      evidence: gatherEvidence(s),
    }));
  
  // 6. 汇总引用
  const citations = gatherCitations(colorAnalysis, paperProfiles);
  
  return {
    id: generateId(),
    generatedAt: new Date().toISOString(),
    summary: { /* ... */ },
    colors: colorAnalysis.results,
    risks,
    recommendations,
    avoidList,
    citations,
  };
}
```

### 9.7 防坑清单

| 坑点 | 防护措施 |
|------|---------|
| **ColorID 映射问题** | 非 SOURCE 颜色必须标注"未验证颜色，建议先映射或打样"，不猜测 |
| **推荐不可追溯** | 每条推荐必须关联：颜色 → PaperProfile → Batch → 审计注记 |
| **工程数据隐私** | 默认不存源文件，只存解析摘要；支持一键删除；审计日志保留但不暴露内容 |
| **AI 编答案** | AI 仅做语言化，必须带引用，不参与裁决 |
