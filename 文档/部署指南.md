## 本地开发

### 1. 克隆项目

```bash
git clone https://github.com/donhauser001/SOURCE.git
cd SOURCE
```

### 2. 安装依赖

```bash
pnpm install
```

### 3. 配置环境变量

```bash
cp apps/web/.env.example apps/web/.env.local
```

编辑 `.env.local`，填写必要的环境变量。

### 4. 初始化数据库

```bash
# 启动本地 PostgreSQL（使用 Docker）
docker compose up -d postgres

# 同步数据库结构
cd apps/web
pnpm prisma db push

# 导入种子数据（可选）
pnpm prisma db seed
```

### 5. 启动开发服务器

```bash
pnpm dev
```

访问 http://localhost:3000

## Docker 部署

### 使用 Docker Compose

```bash
# 构建并启动所有服务
docker compose up -d

# 查看日志
docker compose logs -f web

# 停止服务
docker compose down
```

### Dockerfile（Web 应用）

```dockerfile
# apps/web/Dockerfile
FROM node:20-alpine AS base

# 安装 pnpm
RUN corepack enable && corepack prepare pnpm@latest --activate

# 依赖安装阶段
FROM base AS deps
WORKDIR /app
COPY package.json pnpm-lock.yaml pnpm-workspace.yaml ./
COPY apps/web/package.json ./apps/web/
COPY packages/*/package.json ./packages/*/
RUN pnpm install --frozen-lockfile

# 构建阶段
FROM base AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY --from=deps /app/apps/web/node_modules ./apps/web/node_modules
COPY . .
RUN cd apps/web && pnpm prisma generate
RUN pnpm --filter @source/web build

# 生产镜像
FROM base AS runner
WORKDIR /app
ENV NODE_ENV=production

RUN addgroup --system --gid 1001 nodejs
RUN adduser --system --uid 1001 nextjs

COPY --from=builder /app/apps/web/public ./apps/web/public
COPY --from=builder --chown=nextjs:nodejs /app/apps/web/.next/standalone ./
COPY --from=builder --chown=nextjs:nodejs /app/apps/web/.next/static ./apps/web/.next/static

USER nextjs
EXPOSE 3000
ENV PORT=3000
ENV HOSTNAME="0.0.0.0"

CMD ["node", "apps/web/server.js"]
```

## Vercel 部署

### 1. 连接 GitHub 仓库

1. 登录 [Vercel](https://vercel.com)
2. 点击「Add New Project」
3. 导入 GitHub 仓库 `donhauser001/SOURCE`

### 2. 配置项目

| 设置 | 值 |
|------|---|
| Framework Preset | Next.js |
| Root Directory | `apps/web` |
| Build Command | `pnpm prisma generate && pnpm build` |
| Output Directory | `.next` |

### 3. 配置环境变量

在 Vercel 项目设置中添加以下环境变量：

```
DATABASE_URL=postgresql://...
NEXTAUTH_SECRET=your-secret-key
NEXTAUTH_URL=https://source.ink
EMAIL_SERVER=smtp://...
EMAIL_FROM=noreply@source.ink
```

### 4. 部署

点击「Deploy」开始部署，首次部署约需 3-5 分钟。

## 环境变量

### 必需变量

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `DATABASE_URL` | PostgreSQL 连接字符串 | `postgresql://user:pass@host:5432/source` |
| `NEXTAUTH_SECRET` | NextAuth.js 密钥 | 使用 `openssl rand -base64 32` 生成 |
| `NEXTAUTH_URL` | 应用 URL | `https://source.ink` |

### 邮件配置

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `EMAIL_SERVER` | SMTP 服务器 | `smtp://user:pass@smtp.example.com:587` |
| `EMAIL_FROM` | 发件人地址 | `SOURCE <noreply@source.ink>` |

### 可选变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `NODE_ENV` | 运行环境 | `production` |
| `LOG_LEVEL` | 日志级别 | `info` |

### 生成密钥

```bash
# 生成 NEXTAUTH_SECRET
openssl rand -base64 32

# 或使用 Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

## 数据库配置

### PostgreSQL 生产配置

推荐使用托管数据库服务：

- **Vercel Postgres** - Vercel 原生集成
- **Supabase** - 开源 PostgreSQL 托管
- **Neon** - Serverless PostgreSQL
- **AWS RDS** - 企业级托管

### 连接池配置

对于 Serverless 环境，推荐使用连接池：

```
DATABASE_URL=postgresql://user:pass@host:5432/source?pgbouncer=true&connection_limit=1
```

### 数据库迁移

```bash
# 生产环境迁移
cd apps/web
pnpm prisma migrate deploy
```

## 邮件服务

### 支持的邮件服务

| 服务 | 配置示例 |
|------|---------|
| **Resend** | `smtp://resend:re_xxx@smtp.resend.com:465` |
| **SendGrid** | `smtp://apikey:SG.xxx@smtp.sendgrid.net:587` |
| **AWS SES** | `smtp://AKIAXXXX:secret@email-smtp.us-east-1.amazonaws.com:587` |
| **Gmail** | `smtp://user:app-password@smtp.gmail.com:587` |

### Resend 配置（推荐）

1. 注册 [Resend](https://resend.com)
2. 创建 API Key
3. 验证发送域名
4. 配置环境变量：

```
EMAIL_SERVER=smtp://resend:re_xxxxx@smtp.resend.com:465
EMAIL_FROM=SOURCE <noreply@source.ink>
```

## 常见问题

### Q: 数据库连接失败？

检查 `DATABASE_URL` 格式和网络连通性：

```bash
# 测试连接
psql $DATABASE_URL -c "SELECT 1"
```

### Q: 邮件发送失败？

1. 检查 SMTP 凭据
2. 确认发件人地址已验证
3. 检查邮件服务商限制

### Q: 构建失败？

```bash
# 清理缓存重试
pnpm clean
pnpm install
pnpm build
```
