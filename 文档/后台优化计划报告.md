## 六、关键技术决策

### 6.1 分页策略

**推荐**：Cursor-based Pagination

**理由**：
1. 更适合实时数据（无跳页问题）
2. 性能更好（无需 count 查询）
3. 支持无限滚动

**实现**：
```typescript
// tRPC Router
adminListInfinite: adminProcedure
  .input(z.object({
    limit: z.number().min(1).max(100).default(20),
    cursor: z.string().optional(),
    search: z.string().optional(),
  }))
  .query(async ({ ctx, input }) => {
    const items = await ctx.db.color.findMany({
      take: input.limit + 1,
      cursor: input.cursor ? { id: input.cursor } : undefined,
      where: { /* 搜索条件 */ },
      orderBy: { createdAt: 'desc' },
    });

    let nextCursor: string | undefined = undefined;
    if (items.length > input.limit) {
      const nextItem = items.pop();
      nextCursor = nextItem!.id;
    }

    return { items, nextCursor };
  });
```

**实现**：

import { inngest } from '@/lib/inngest';

export const importColors = inngest.createFunction(
  { id: 'import-colors' },
  { event: 'import/colors' },
  async ({ event, step }) => {
    const { colors } = event.data;

    for (let i = 0; i < colors.length; i++) {
      await step.run(`import-${i}`, async () => {
        await db.color.create({ data: colors[i] });

      // 进度反馈
      await step.sendEvent('import-progress', {
        data: { current: i + 1, total: colors.length },

    }
  }
);
