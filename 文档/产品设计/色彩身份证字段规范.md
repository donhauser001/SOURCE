# Color Identity 页面字段清单（v1.0）

> **一句话总结**：Color Identity 页面集中呈现某一颜色的真源定义、适用纸张、可行配方、验证证据与风险限制，是 SOURCE 的最小完整事实单元。

---

## 字段标注说明

| 标记 | 含义 |
|------|------|
| **M** | 必须字段（Must have） |
| **R** | 推荐字段（Recommended） |
| **E** | 可扩展字段（Extensible） |

---

## 0️⃣ 页面元信息（Meta）

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `color_id` | 唯一颜色编号（不可变） | String | M |
| `color_name` | 官方名称（文化命名） | String | M |
| `color_slug` | URL 标识 | String | M |
| `status` | active / deprecated / experimental | Enum | M |
| `version` | 当前页面版本 | String | R |
| `last_verified_at` | 最近一次整体验证时间 | Date | R |

---

## 1️⃣ 真源区 · True Source（唯一锚点）

> 本区字段全局唯一，禁止多值

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `lab_l` | 真源 L* | Number | M |
| `lab_a` | 真源 a* | Number | M |
| `lab_b` | 真源 b* | Number | M |
| `delta_e_tolerance` | 允许偏差 ΔE | Number | M |
| `measurement_device` | 分光测色仪型号 | String | M |
| `measurement_standard` | 测量标准（如 D50/2°） | String | M |
| `measurement_condition` | 测量条件说明 | Text | R |
| `true_source_note` | 真源说明 | Text | R |

---

## 2️⃣ 推荐纸张场景 · Paper Scenarios

> 限定讨论空间的前置条件

### 2.1 推荐纸张（白名单）

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `paper_id` | 纸张 ID | String | M |
| `paper_name` | 纸张名称 | String | M |
| `paper_type` | 涂布 / 非涂布 / 特种 | Enum | M |
| `reason` | 推荐理由 | Text | R |

### 2.2 排除纸张（黑名单）

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `paper_id` | 纸张 ID | String | M |
| `reason` | 不推荐原因 | Text | M |

---

## 3️⃣ 配方总览 · Recipes Overview（一对多）

> 一个 Color ID 可关联多条 Recipe

### 3.1 配方基础信息

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `recipe_id` | 配方编号 | String | M |
| `recipe_name` | 内部名称 | String | R |
| `status` | experimental / verified / deprecated | Enum | M |
| `cost_level` | 低 / 中 / 高 | Enum | M |
| `applicable_papers` | 适用纸张 ID 列表 | Array | M |
| `notes` | 简要说明 | Text | R |

### 3.2 油墨构成（Recipe Core）

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `ink_name` | 油墨名称 | String | M |
| `ink_type` | 基础色 / 专色 / 冲淡剂 | Enum | M |
| `percentage` | 比例（%） | Number | M |

> 多条记录组成一条配方

---

## 4️⃣ 配方 × 纸张适配矩阵 · Fit Matrix（核心）

> Color Identity 的心脏

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `recipe_id` | 配方 ID | String | M |
| `paper_id` | 纸张 ID | String | M |
| `fit_result` | recommended / usable / not_recommended | Enum | M |
| `delta_e_result` | 实测 ΔE | Number | R |
| `stability_score` | 稳定性评分（1–5） | Number | R |
| `issue_tags` | 风险标签 | Array | R |
| `conclusion_note` | 结论说明 | Text | M |
| `report_ids` | 支撑报告 ID | Array | M |

---

## 5️⃣ 按纸张推荐配方 · Recommended Recipes

> 禁止全局推荐，必须带纸张条件

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `paper_id` | 纸张 ID | String | M |
| `recommended_recipe_id` | 推荐配方 | String | M |
| `reason` | 推荐理由 | Text | M |
| `confidence_level` | 高 / 中 / 低 | Enum | R |

---

## 6️⃣ 配方测试报告 · Recipe Test Reports（证据）

> 摘要展示，完整内容在 ColLab

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `report_id` | 报告编号 | String | M |
| `recipe_id` | 关联配方 | String | M |
| `tested_papers` | 测试纸张 ID | Array | M |
| `printer_partner` | 印厂 / 实验机构 | String | M |
| `press_model` | 印刷机型号 | String | R |
| `test_date` | 测试日期 | Date | M |
| `measurement_device` | 测量仪器 | String | M |
| `conclusion_level` | pass / conditional / fail | Enum | M |
| `summary` | 结论摘要 | Text | M |
| `collab_link` | ColLab 链接 | URL | R |

---

## 7️⃣ 风险与限制 · Risks & Limitations

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `risk_type` | 色偏 / 发灰 / 绝网 / 不稳定 | Enum | M |
| `affected_papers` | 受影响纸张 | Array | M |
| `description` | 风险说明 | Text | M |
| `mitigation` | 规避建议 | Text | R |

---

## 8️⃣ 审计与溯源 · Audit & Traceability

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `audit_status` | verified / under_review | Enum | M |
| `auditors` | 审计人 / 机构 | Array | M |
| `audit_notes` | 审计说明 | Text | R |
| `last_audit_at` | 最近审计时间 | Date | R |

---

## 9️⃣ 页面声明 · Official Statement（固定区块）

> 不随 Color 变化的标准声明

- SOURCE 不提供脱离纸张条件的通用配方
- 推荐配方为默认生产条件下的工程最优解
- 所有结论均基于实体验证

## 数据模型关系图

```
Color (1)
  ├── TrueSource (1:1)
  ├── PaperRecommendation (1:N) ── Paper
  ├── Recipe (1:N)
  │     ├── RecipeIngredient (1:N)
  │     ├── FitMatrix (1:N) ── Paper
  │     └── RecipeTestReport (1:N)
  ├── PaperRecipeRecommendation (1:N)
  ├── Risk (1:N)
  └── Audit (1:N)
```
