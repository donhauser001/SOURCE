# Color Identity 页面字段清单（v1.0）

> **一句话总结**：Color Identity 页面集中呈现某一颜色的真源定义、适用纸张、可行配方、验证证据与风险限制，是 SOURCE 的最小完整事实单元。

---

## 字段标注说明

| 标记 | 含义 |
|------|------|
| **M** | 必须字段（Must have） |
| **R** | 推荐字段（Recommended） |
| **E** | 可扩展字段（Extensible） |

---

## 0️⃣ 页面元信息（Meta）

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `color_id` | 唯一颜色编号（不可变） | String | M |
| `color_name` | 官方名称（文化命名） | String | M |
| `color_slug` | URL 标识 | String | M |
| `status` | active / deprecated / experimental | Enum | M |
| `version` | 当前页面版本 | String | R |
| `last_verified_at` | 最近一次整体验证时间 | Date | R |

## 1️⃣ 真源区 · True Source（唯一锚点）

> 本区字段全局唯一，禁止多值

| 字段 | 说明 | 类型 | 必须 |
|------|------|------|------|
| `lab_l` | 真源 L* | Number | M |
| `lab_a` | 真源 a* | Number | M |
| `lab_b` | 真源 b* | Number | M |
| `delta_e_tolerance` | 允许偏差 ΔE | Number | M |
| `measurement_device` | 分光测色仪型号 | String | M |
| `measurement_standard` | 测量标准（如 D50/2°） | String | M |
| `measurement_condition` | 测量条件说明 | Text | R |
| `true_source_note` | 真源说明 | Text | R |

## 9️⃣ 页面声明 · Official Statement（固定区块）

> 不随 Color 变化的标准声明

- SOURCE 不提供脱离纸张条件的通用配方
- 推荐配方为默认生产条件下的工程最优解
- 所有结论均基于实体验证

## 🔟 双模式视图 · View Modes

> SOURCE 色彩身份证提供两种查看模式，满足不同用户群体的需求。

### 10.1 设计师模式（Designer Mode）

| 特性 | 说明 |
|------|------|
| **目标用户** | 设计师、品牌方、非色彩专业人士 |
| **核心理念** | 直观、快速、风险预警优先 |
| **视觉风格** | 极简单色调、清晰层级、无数据噪音 |

**展示内容**：
- 色彩还原度快评（优秀/良好/需注意）
- 纸张推荐星级（5 星制）
- 风险预警标签（大色块/渐变/叠印等）
- 适用场景建议

**设计原则**：
- 用自然语言替代技术术语
- 用图形化指标替代数字
- 强调"能不能用"而非"为什么"

### 10.2 专家模式（Expert Mode）

| 特性 | 说明 |
|------|------|
| **目标用户** | 印刷工程师、调色师、质控人员 |
| **核心理念** | 精密数据、可交互图表、完整分析 |
| **视觉风格** | 深色背景、专业图表、数据密集 |

**展示内容**：
- Lab 色度坐标图（a*b* 平面）
- L* 明度标尺
- ΔE 容差范围可视化（容差范围 + 警戒范围）
- 各纸张漂移向量
- 交互功能：缩放、平移、聚焦真源

**核心组件**：

| 组件 | 功能 | 交互 |
|------|------|------|
| ChromaticityPlot | Lab a*b* 色度平面图 | 滚轮缩放、拖拽平移、双指手势 |
| LightnessScale | L* 明度渐变标尺 | 与色度图联动缩放 |
| Toolbar | 视图控制工具栏 | 缩放、重置、聚焦真源、图层开关 |

**图层控制**：
- 容差范围（ΔE 容差椭圆）
- 警戒范围（2x ΔE 椭圆）
- 连接线（纸张漂移向量）
- 纸型显示（下拉多选）

### 10.3 模式切换

```typescript
type ViewMode = 'designer' | 'expert';

interface ViewModeContext {
  mode: ViewMode;
  setMode: (mode: ViewMode) => void;
}
```

模式切换按钮位于色彩表现卡片右上角，支持响应式显示：
- 桌面端：图标 + 文字（"设计师模式" / "专家模式"）
- 移动端：仅图标

### 10.4 响应式适配

| 设备 | 布局特点 |
|------|---------|
| **桌面端** | 左右分栏（色度图 + 明度标尺）、完整工具栏、悬停提示 |
| **平板端** | 压缩布局、单行工具栏、增大触控目标 |
| **移动端** | 纵向堆叠、可折叠工具栏、横向明度条、支持双指缩放 |
