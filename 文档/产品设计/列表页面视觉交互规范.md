# SOURCE 列表页面视觉交互规范

> 基于色彩库页面设计标准，适用于所有列表类页面的视觉与交互设计。

---

## 一、设计原则

### 1.1 核心理念
- **全圆角风格**：所有交互元素采用圆角设计，营造柔和现代感
- **单色主调**：以灰黑白为主色调，内容色彩来自数据本身
- **动效曲线**：统一使用 `cubic-bezier(0.4, 0, 0.2, 1)` 缓动函数
- **动态适应**：样式根据内容（如颜色明度）动态调整

### 1.2 色彩体系
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色 | `gray-900` (#111827) | 选中态、强调文字、徽章背景 |
| 文字 | `gray-700` (#374151) | 主要文字 |
| 辅助文字 | `gray-500` (#6B7280) | 次要文字、图标 |
| 占位文字 | `gray-400` (#9CA3AF) | placeholder、禁用态 |
| 背景 | `gray-100` (#F3F4F6) | 工具栏背景 |
| 容器 | `white` (#FFFFFF) | 按钮、卡片、输入框背景 |
| 分隔线 | `gray-300` (#D1D5DB) | 分隔元素 |

## 二、工具栏规范

### 2.1 容器样式

### 2.2 搜索框

#### 收缩态
- 尺寸：`44px × 44px` (h-11 w-11)
- 圆角：全圆角 `rounded-full`
- 背景：白色
- 图标：`20px × 20px` (h-5 w-5)，灰色 `gray-500`
- 悬停：背景 `gray-50`

#### 展开态
- 高度：`44px` (h-11)
- 宽度：弹性填充 `flex-1`
- 内边距：左 `48px` (pl-12)，右 `40px` (pr-10)
- 关闭按钮：`24px × 24px`，灰色图标

#### 动画
- 过渡时长：`500ms`
- 缓动函数：`cubic-bezier(0.4, 0, 0.2, 1)`
- 触发条件：点击展开，失焦且无内容时收缩

## 五、卡片组件规范

### 5.1 通用样式

#### 边框系统
```css
/* 动态边框透明度 - 根据内容明度计算 */
opacity = 0.15 + (lightness / 100) × 0.45
/* 深色内容: ~15% 透明度 */
/* 浅色内容: ~60% 透明度 */

/* 悬停时 */
border-opacity: 100%;
```

#### 过渡动画
```css
transition: all 500ms cubic-bezier(0.4, 0, 0.2, 1);
```

### 5.2 极简卡片 (MinimalColorCard)

#### 结构
```
┌─────────────────┐
│                 │ ← 色块区域 (1:1 正方形)
│    [实验中]     │ ← 状态标签 (右上角)
│                 │
├─────────────────┤
│ 名称 ✓          │ ← 信息区域
│ CN-XXX-01       │
└─────────────────┘
```

#### 样式参数
- 圆角：`24px` (rounded-3xl)
- 边框：`4px`，颜色动态
- 色块：`aspect-square`
- 信息区：`padding: 12px` (p-3)

#### 悬停效果
1. 色块铺满整个卡片
2. 信息区背景透明
3. 文字颜色根据底色明度自动反转
4. 边框透明度变为 100%

### 5.3 列表卡片 (ColorListItem)

#### 结构
```
┌──────┬───────────────────────┬──────────┐
│      │ 名称 ✓ CN-XXX-01      │          │
│ 色块 │ L*50 a*+10 b*-20 [蓝] │ [实验中] │
│      │                       │          │
└──────┴───────────────────────┴──────────┘
```

#### 样式参数
- 圆角：全圆角 `rounded-full`
- 边框：`4px`，颜色动态
- 色块宽度：`33.333%` (w-1/3)
- 信息区：`padding: 12-16px` (p-3 sm:p-4)
- 状态区：`padding: 16-20px` (px-4 sm:px-5)

#### 悬停效果
1. 色块从 1/3 扩展到 100%
2. 文字、图标、标签颜色自动反转
3. 右箭头淡入并位移
4. 边框透明度变为 100%

### 5.4 状态标签

#### 实验中标签
```css
.experimental-tag {
  padding: 4px 12px;    /* px-3 py-1 */
  font-size: 12px;      /* text-xs */
  border-radius: 9999px;
  background: #1F2937;  /* bg-gray-800 */
  color: white;
}

/* 悬停反色（根据背景明度） */
.experimental-tag.hover-light {
  background: #111827;
  color: white;
}
.experimental-tag.hover-dark {
  background: white;
  color: #111827;
}
```

#### 状态图标
- 已验证：`ShieldCheck` 图标，`14px` (h-3.5 w-3.5)
- 实验中：`FlaskConical` 图标，`14px` (h-3.5 w-3.5)
- 默认色：`gray-500`
- 悬停色：根据背景明度自动反转

### 5.5 色系标签
```css
.color-family-tag {
  padding: 2px 8px;     /* px-2 py-0.5 */
  font-size: 10px;      /* text-[10px] */
  border-radius: 9999px;
  border: 1px solid #9CA3AF;  /* border-gray-400 */
```

## 八、交互行为规范

### 8.1 状态持久化
- 视图模式存储到 `localStorage`
- 筛选条件变化时重置分页
- 视图模式变化时重置分页

### 8.2 动画时长标准
| 动作 | 时长 | 缓动函数 |
|------|------|----------|
| 搜索框展开/收缩 | 500ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 卡片悬停效果 | 500ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 边框颜色变化 | 500ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 筛选选项切换 | 150ms | ease |
| 箭头淡入位移 | 300ms | ease-out |
| 页面滚动 | smooth | - |

### 8.3 响应式交互
- 移动端：筛选按钮可折叠
- 触摸设备：悬停效果转为点击态
